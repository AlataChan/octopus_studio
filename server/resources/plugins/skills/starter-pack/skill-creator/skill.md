# Skill Creator (Skill Creation Assistant)

This skill helps you upgrade temporary conversational collaboration into a reusable skill asset.
I first guide you to describe the workflow to standardize: trigger conditions, input materials, output deliverables, things it must not do, and success criteria.
Then I provide a draft structure for skill.md (frontmatter + body sections), and suggest tags, categories, and tool declarations to ensure it follows validation rules.
If you already have old documents, scripts, or templates, I read them and extract key steps, rewriting them into clear operating instructions and example inputs and outputs.
Finally, I provide a pre-release checklist to help you self-check consistency and risks before publishing.

## Intended Users

- PMs, operations owners, and technical leads responsible for knowledge capture and process standardization
- Teams that want to turn frequent tasks, such as weekly reports, reviews, and alignment work, into one-click reusable capabilities
