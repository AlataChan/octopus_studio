# File Organizer (Archiving/Naming/Directory Structure)

This skill turns a folder that keeps getting messier into a structure that can be maintained over the long term.
I first read the directory listing and identify duplicate, temporary, and outdated content, as well as search problems caused by inconsistent naming.
Then I provide naming and directory-layering suggestions, such as organizing by project, time, or function, plus migration steps and a rollback strategy to avoid a risky one-time move.
If you are worried about collaboration impact, I recommend a phased migration: add indexes and shortcuts first, then gradually archive and rename files.
The final deliverables include a target directory tree, naming conventions, and an old-to-new mapping table.

## You Can Provide

- Current directory screenshot or list, or let the system list it directly
- Expected usage over the next three months: who will use it and how they will find things
