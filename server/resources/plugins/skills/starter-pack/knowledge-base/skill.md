# Knowledge Base Operations (Capture/Retrieval/Reuse)

This skill addresses a common collaboration pain point: knowledge is scattered across chats, documents, and tickets, making it hard to find and reuse.
You provide the current material types and typical search questions people ask, and I first design a taxonomy and tag system to prevent the knowledge base from becoming chaotic over time.
Then I define intake standards: what is worth capturing, how to name it, and which fields must be included, such as background, conclusion, scope of use, and last updated time.
On the retrieval side, I map common questions to keywords and graph relationships, then provide an iterative retrieval strategy and hit-rate evaluation metrics.
Finally, I output an operating cadence: weekly or monthly cleanup, recycling repeated questions, knowledge expiration reminders, and ownership mechanisms.

## Common Outputs

- Category and tag dictionary with examples
- Intake template and naming conventions
- Search-question list and optimization suggestions
