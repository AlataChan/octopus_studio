# Word Office (Generation/Rewriting/Review Suggestions)

This skill covers common office needs for .docx documents: writing a document from scratch, or rewriting and reviewing an existing one.
You provide a document file or paragraph excerpts, and I first identify the document type (report, proposal, contract, or notice), then provide matching structure suggestions.
For rewriting tasks, I preserve the original meaning while improving logic and wording, avoiding the risk of text that looks polished but changes the information.
For review tasks, I point out unclear wording, potential ambiguity, and missing information, then provide replacement text you can use directly.
The output can be a summary or review checklist, or paragraph-by-paragraph rewriting suggestions organized by section.

## Common Requests

- "Make this paragraph more professional or easier to read"
- "Find weaknesses in this proposal and suggest improvements"
- "Generate a project overview document based on this template"
