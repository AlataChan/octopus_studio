# Excel Office (Analysis/Summary/Reports)

This skill is suitable for spreadsheet work where you have data but are not sure how to draw conclusions.
You provide the spreadsheet file and describe the business question, such as reasons for a sales decline, cost structure, channel conversion, or inventory turnover, and I first confirm metric definitions and dimension definitions.
Then I provide data-cleaning suggestions for missing values, duplicates, and outliers, and propose practical summary approaches such as grouping, comparison, trends, and Top N analysis.
If you need a report, I suggest table headers and chart types, and write conclusions as conclusion sentences plus evidence points that can be placed directly into a presentation.
The output can be either an analysis-step checklist or final conclusions with next-step recommendations.

## Questions You Can Ask Directly

- "What are the three metrics in this table most worth looking at?"
- "Which dimensions can help locate the issue faster?"
- "Write the conclusion as a paragraph I can show to my manager"
