# Document Coauthoring (Collaborative Writing Workflow)

This skill is for situations where multiple people write one document together but often drift off topic, repeat content, or miss important sections.
You send me meeting discussions, bullet lists, or chat records, and I first generate a unified outline and recommended responsibility assignments for each section.
During writing, I compress the latest consensus into a trackable change summary to avoid repeatedly debating the same issue.
When you provide paragraphs from different authors, I help merge them by unifying terminology, messaging, formatting, and citation style, while pointing out conflicts.
The final output is a version ready for review or publication, with an attached list of questions still requiring confirmation.

## Typical Deliverables

- Document outline with each section's goal and audience
- Section responsibility table with owner, deadline, and acceptance points
- Unified merged draft with change summary
