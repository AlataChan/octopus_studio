# PPT Office (Outline/Structure/Speaker Notes)

This skill helps turn what you want to say into a presentation structure that the audience can understand and remember.
You provide the topic, audience profile, time length, and desired action such as decision, purchase, alignment, or training, and I first design the storyline and slide-level structure.
If you provide existing PPT content, I identify information overload and logical jumps, then suggest deletion, reordering, and visualization approaches.
In addition to slide-level points, I output speaker notes (30-60 seconds per slide) and a list of likely questions to help you rehearse.
The default output is organized as slide number to title to key points to speaker notes, making it easy to fill back into slides.

## Common Structure Templates

- Current state and problem -> solution -> value -> plan -> decisions needed
- Goal -> method -> results -> lessons learned -> next steps
