# Project Plan (Milestones/Risks/Dependencies)

This skill turns the idea of doing a project into a trackable plan.
You provide the goal, scope boundaries (in and out of scope), time window, team roles, and known constraints such as budget, compliance, or dependent systems.
I first break the work into phases and milestones, then define the acceptance criteria and deliverables for each milestone.
Next, I map key dependencies and paths: which tasks must be completed first, which can run in parallel, and where the critical path and buffer points are.
Finally, I provide a risk list and response strategies, and recommend a cadence for weekly meetings or recurring project tracking.

## Output Includes

- WBS/milestone table with owner and date suggestions
- Risks and assumptions with trigger signals and mitigation measures
- Dependency and critical path explanation
