# Security Policy

## Supported Versions

The latest `1.x` release line receives security updates.

| Version | Supported          |
| ------- | ------------------ |
| 1.x     | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security concern affecting **Octopus Studio**, please:

- For non-sensitive concerns, open an issue in this repository and label it `[security]`.
- For vulnerabilities that must remain private, use GitHub's private vulnerability reporting for `AlataChan/octopus_studio` when available. Do not publish exploit details in a public issue.

If the issue also affects the upstream project **AnythingLLM** maintained by Mintplex Labs, please follow the security reporting process described in the upstream repository.
