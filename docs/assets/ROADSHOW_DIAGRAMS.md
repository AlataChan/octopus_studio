## 截图获取指南

### 步骤 1: 启动开发服务

```bash
cd /Users/apple/Alata-studio
yarn dev:server    # 终端 1
yarn dev:frontend  # 终端 2
```

### 步骤 2: 访问各页面

| 截图 | URL |
|-----|-----|
| 首页轮播 | `http://localhost:3000/` |
| 员工库 | `http://localhost:3000/assistant-library` |
| 对话界面 | `http://localhost:3000/workspace/[slug]` |
| 知识图谱 | `http://localhost:3000/workspace/[slug]/graph` |
| LLM 配置 | `http://localhost:3000/settings/llm-preference` |
| API Key | `http://localhost:3000/settings/api-keys` |

### 步骤 3: 截图工具

- **macOS**: `Cmd + Shift + 4` 区域截图
- **Chrome DevTools**: 设备模式 → 截图
- **推荐分辨率**: 1920x1080 或 2560x1440

### 步骤 4: 后处理

1. 隐藏浏览器 UI（书签栏、扩展图标）
2. 使用深色模式（视觉冲击力更强）
3. 填充演示数据（真实但脱敏）
4. 添加适当的标注和箭头
